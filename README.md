# Proyecto Análisis de Ventas

## Integrante

Cristian Detter

## Escenario elegido

Escenario B - Análisis de Ventas de una Pequeña Empresa

## Descripción

Este proyecto fue realizado para la materia Organización Empresarial de la UTN.

El objetivo es analizar un conjunto de datos de ventas para obtener indicadores básicos como ventas totales, producto más vendido y evolución de ventas a lo largo del tiempo.

## Estructura del repositorio

* datos/: contiene los archivos de datos utilizados.
* scripts/: contiene los scripts desarrollados en Python.
* resultados/: contiene los gráficos y resultados obtenidos.

## Ejecución

1. Colocar el archivo de ventas en la carpeta datos.
2. Ejecutar el script ubicado en la carpeta scripts.
3. Consultar los resultados generados en la carpeta resultados.
